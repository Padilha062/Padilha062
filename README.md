# Olá 👋, eu sou Vitor Padilha

🚀 **Sales Operations Analyst | Dados & Automação**  
🇧🇷 Brasil

Atuo com **operações comerciais**, **business intelligence** e **automação de processos**, ajudando equipes a tomarem decisões mais estratégicas através de dados e eficiência operacional.

Meu foco está na criação de processos escaláveis, dashboards, automações e soluções orientadas a dados que aumentem a performance e otimizem as operações da empresa.

Atualmente, trabalho com tecnologias como **Python, SQL, PostgreSQL, Power BI, Excel e Google Sheets**, conectando análise de dados e tecnologia para resolver desafios operacionais e comerciais.

Também possuo experiência com desenvolvimento de software utilizando **.NET, C#, Angular, Git e GitHub**.
